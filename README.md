# SkyZoom Client (Fabric, Minecraft 26.3)

Build (JDK 25 + Gradle 9.5.1):  gradle build  ->  build/libs/skyzoom-1.1.0.jar
Or push to GitHub: Actions > build > download the "skyzoom-jar" artifact.
Put the jar (not -sources) in .minecraft/mods with Fabric Loader + Fabric API.

Menu: Right Shift. Left click = toggle module, right click = open settings, drag sliders.
Keys (rebindable): C zoom, K time, J weather, F8 freecam, F9 HUD,
unbound by default: freecam control-player toggle, panic.
